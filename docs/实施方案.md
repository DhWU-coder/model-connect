# Model Connect 实施方案

1. 创建 Python 包、安装入口、静态资源目录与开发依赖，忽略虚拟环境、IDE 配置和运行缓存。
2. 实现配置与数据模型，包括 provider、路径覆盖、匹配规则、探测参数和明确的结果状态。
3. 实现三种原生 provider 与 OpenAI 兼容适配器；处理列表分页、认证、协议切换、返回文本与错误分类。
4. 实现异步任务队列、并发/超时/重试、取消、进度快照与 CSV/JSON 导出，清理过期任务中的引用。
5. 实现本地 HTTP 服务与中文网页；支持筛选、手动模型、实时进度、任务恢复、结果展开与导出。
6. 实现 CLI 前后台启动、重启、停止、状态、日志、文件锁与 PID 身份检查。
7. 编写关键行为测试，运行本地模拟服务与 CLI 集成验证，并验证网页脚本和关键 UI 操作。
8. 补全 README、安装与使用说明，安装到本目录已有 .venv，并通过 uv 安装用户终端命令。完成本地 Git 提交并推送到用户指定的远程仓库。

所有手写代码注释和说明使用中文。直接在当前目录实施，不创建工作树、不自行创建额外分支、不使用子代理。
