# Model Connect 设计文档

## 目标

提供本地中文网页，按实际请求验证模型的文本生成能力。模型列表仅作为候选目录，不能直接作为连通性结论。通过 `model-connect start/restart/run/stop/end` 管理服务。

## Provider 与协议

| 配置 | 默认 API 根地址 | 模型列表 | 探测方式 |
| --- | --- | --- | --- |
| OpenAI | https://api.openai.com/v1 | GET models | 默认 Chat Completions，可选择 Responses 或分别检测两者 |
| OpenAI 兼容 | 用户指定 | GET models | 默认 Chat Completions，可选择 Responses |
| Anthropic | https://api.anthropic.com/v1 | GET models，after_id 分页 | POST messages |
| Google Gemini | https://generativelanguage.googleapis.com/v1beta | GET models，pageToken 分页 | POST models/{模型}:generateContent |

Provider 代表接口协议，不能通过模型名称猜测协议。API 根地址保留用户指定的网关前缀，自动补全官方默认版本目录。高级配置可覆盖列表路径、调用路径及附加请求头，以兼容中转站。Google 首版采用 Gemini Developer API 的 API Key 鉴权。

不同适配器负责鉴权、分页、请求体构建、返回文本提取和错误分类。OpenAI 使用 Bearer；Anthropic 使用 x-api-key 与 anthropic-version，并允许附加 workspace 请求头；Google 使用 x-goog-api-key。

## 检测语义

默认提示词为「只回复hi」，默认输出 Token 上限为 64，默认并发数为 5，可手动调整为 1～20。收到符合协议的非空文本才算文本生成成功，不要求字面上严格等于 hi。HTTP 200 但无文本、格式错误、内容拒绝或 token 预算耗尽须分别说明。保留耗时、HTTP 状态码、错误类型、回复、模型返回名称及实际协议。

OpenAI 与 OpenAI 兼容服务默认检测 Chat Completions，以便优先验证常见网关接口。仍可分别检测 Chat Completions 与 Responses；选择两者时，每个模型保留两条结果，避免一个协议成功掩盖另一个失败。列表中可明确识别的嵌入、音频、图像、实时等专用模型标记为不适用；Google 优先依据 supportedGenerationMethods 并结合专用生成模型名称判断。未知名称仍进行真实检测，不能仅凭名称认定不可用。支持手动输入模型并覆盖不适用判断。

错误分为鉴权失败、权限不足、额度不足、限流、模型或接口不存在、参数/能力不支持、服务错误、网络错误、超时、无文本、响应格式错误。结论只描述本次请求，不推导模型永久不可用。默认不重试，避免增加调用量；可设置少量重试，只重试超时、网络、429 和 5xx。并发数、每个请求的超时、最大输出 token 数及提示词可调。

## 筛选与任务

支持包含、前缀、后缀、通配符和精确匹配；通配符使用 fnmatch 语义，`*` 匹配任意长度，`?` 匹配一个字符，`**_flash_**` 与 `*_flash_*` 等价。多行规则按「或」匹配，可选择大小写敏感。UI 预览筛选结果、勾选模型后创建检测任务。

异步任务采用有界 worker 队列控制并发，每个模型/协议独立记录状态。浏览器定时读取快照，刷新后可通过任务 ID 恢复当前任务。取消时停止排队与进行中的请求。结果支持 JSON 和 CSV 下载。进程内保留有限数量任务；服务重启后历史清空，不保存 API Key。

## UI

单页中文界面，桌面采用左侧配置、右侧模型及结果布局，小屏纵向排列。包含 provider 选择、Base URL、密码样式 API Key、列表获取、手动模型、筛选与全选、检测参数、进度统计、状态筛选、详细结果与导出。表格展示模型、协议、状态、耗时、回复或错误。默认不自动打开浏览器。

主题支持跟随系统、浅色和深色，在顶部切换，默认跟随系统。仅将主题偏好写入浏览器 localStorage。主题脚本在样式表加载前恢复偏好，避免已选择深色时先显示浅色；系统主题变化时自动更新跟随系统模式。表单、模型列表、状态标签、提示和结果表格共用主题颜色变量。

Provider、API 根地址和 API Key 使用当前标签页的 sessionStorage 保存输入，刷新时在请求本地服务前恢复，不做长期保存。刷新后 Key 仍以密码形式显示；切换 provider 时沿用原有重置地址并清空密钥的行为，并同步更新会话快照，避免恢复旧 provider 的凭据。模型列表获取成功后保存规范化地址，手动清空也覆盖旧值。高级连接设置仍在刷新时清空。存储不可用或保存数据损坏时回退到默认表单，不影响当前页输入和检测。

调用成功与调用失败统计区域可点击，通过弹窗显示对应模型名称、协议、耗时及回复或错误。弹窗使用当前任务的完整结果快照，独立于主表状态筛选，检测中实时更新；双协议按调用记录分别展示，同时显示去重模型数与记录数。无结果时展示空状态。支持键盘打开、Esc 或关闭按钮退出，关闭后焦点回到入口，并沿用深浅主题与手机布局，不重新请求上游。

## CLI 与进程管理

使用 Python 包入口与 argparse，默认监听 0.0.0.0:8886，允许局域网设备通过服务器的局域网 IP 访问。start 启动独立后台子进程并确认健康；run 在前台运行，同样可通过 stop/end 停止；restart 默认沿用已有监听地址；status 与 logs 辅助查看运行状态。PID、启动标识和日志写入用户状态目录，可用 MODEL_CONNECT_STATE_DIR 覆盖。

通过跨进程文件锁阻止并发启动，启动前检测端口占用，停止前检查进程身份，避免 PID 重用导致停止其他程序。SIGTERM 正常停止，超时才强制终止。服务日志与任务导出都不包含请求头或 API Key。

## 本地与局域网访问

默认监听所有 IPv4 网卡，局域网设备通过服务器的局域网 IP 访问，本机仍可使用 127.0.0.1。可显式使用 --host 127.0.0.1 限制为本机访问。不启用跨域，接口校验浏览器 Origin 与 Host，拒绝来自其他网页的跨站写操作。UI 不在 localStorage 保存 API Key，下载报告对凭据脱敏，README 说明本工具无账号体系。

## 技术与验证

Python 3.11+、FastAPI、Uvicorn、HTTPX、原生 HTML/CSS/JavaScript，无前端打包要求。pytest 与 HTTPX MockTransport 验证协议、分页、筛选、错误分类、取消及重试；本地模拟 provider 验证 UI 到真实 HTTP 请求链路；CLI 集成验证前后台启停、重复启动、端口冲突与身份检查。无真实密钥时不宣称已验证官方服务连通性。
