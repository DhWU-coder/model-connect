## 首次验证运行状态与限制

首次验证时默认端口 8765 已被其他程序占用，因此当时本地服务使用 127.0.0.1:8766。模拟 provider 在验证结束后停止。

随后按用户要求停止本地服务，并将默认端口调整为 8886，交由用户自行启动。端口调整通过不启动服务的模拟调用检查，验证默认参数、显式端口和重启沿用端口的行为。

用户确认后，默认监听地址调整为 0.0.0.0，端口保持 8886。11 项接口与非启动 CLI 测试通过，Ruff 检查与格式检查通过。模拟 CLI 调用验证默认地址、显式覆盖和重启沿用配置；内存 HTTP 请求验证局域网 IP 的页面、健康接口和同源筛选请求可用，跨站请求仍返回 403。验证期间未启动或停止用户服务；用户此前启动的实例需要自行重启以应用新监听配置。

没有用户真实 API Key，本记录不表示已验证官方线上账号的权限、额度或实际模型可用性。进程管理已在当前 macOS 机器验证；Linux 和 Windows 需要在对应系统进一步验证。
